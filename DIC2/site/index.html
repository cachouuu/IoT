03 / CRISP-DM WORKFLOW

讓分析可以重做，讓結果可以查核。

01

理解問題

預測 Profit 或 MEDV。定義目標與單位，先理解資料的使用情境。

02

認識資料

檢查欄位、缺失與重複。Boston 使用 506 筆歷史樣本，MEDV 單位為千美元。

03

準備資料

先分訓練與測試，再依訓練資料處理缺失與類別編碼。

04

建立模型

比較 Lasso 排序、Forward SFS、RFE、Elastic Net 排序與窮舉。每個子集重估 OLS。

05

評估表現

用訓練 CV 選特徵和 k；保留測試集評估 RMSE、MAE 與 R²。

06

交付與重用

兩題套用同一 Python 工作流程。此互動介面另支援自訂 CSV 的瀏覽器分析。

Boston Housing 為課堂歷史資料：MEDV 有 50 的上限，B 欄位包含有爭議的種族相關設計；結果僅供此資料的迴歸練習，不作現代房價或政策判斷。
